# Additional Korean glyphs

The approved exhibition fonts are local subsets. The website adds 10 Hangul syllables used by its new copy: 궤 돕 듭 멈 섯 쌓 줍 짚 켠 펴.

Official source: https://fonts.googleapis.com/css2?family=Noto+Sans+KR%3Awght%40300..900&display=swap&text=%EA%B6%A4%EB%8F%95%EB%93%AD%EB%A9%88%EC%84%AF%EC%8C%93%EC%A4%8D%EC%A7%9A%EC%BC%A0%ED%8E%B4

The Noto Sans KR variable subset is served locally as `noto-kr-additional.woff2` (3192 bytes), under the bundled SIL OFL. No font request is made to Google at runtime. The additional face only covers those code points and does not alter existing font assets.
