개인정보처리방침

Orbit Chrome 확장 프로그램 · 시행일 2026년 11월 5일

Team Orbit(이하 “Orbit”)은 Orbit Chrome 확장 프로그램과 이를 지원하는 Orbit 서버(이하 “서비스”)를 운영하며, 「개인정보 보호법」 등 관련 법령에 따라 이용자의 개인정보를 처리합니다. 이 방침은 서비스가 어떤 정보를 왜 수집하고, 어디에 보내고, 얼마나 보관하며, 이용자가 어떻게 통제할 수 있는지를 설명합니다.

요약
  • Google 로그인 후, 이용자가 수집을 켠 동안 방문한 페이지의 제목·주소·방문 시각·본문 일부를 탐색 기록으로 저장합니다.
  • 기록은 세션 정리·검색·질문 답변을 위해 Orbit 서버에 저장되고, 일부는 외부 AI 서비스로 보내 처리합니다.
  • 시크릿 창은 기록하지 않습니다. 금융·결제·일부 공공 사이트 등 민감한 페이지는 기본으로 제외합니다.
  • 팀 기능은 이용자가 직접 공유하거나 팀 수집을 켠 기록만 팀원에게 보여 줍니다.
  • 개인정보를 판매하거나 광고·신용평가에 쓰지 않습니다.

1. 처리하는 개인정보와 목적

항목내용목적
계정 정보 Google 계정 식별자, 이메일, 이름, 프로필 사진, Orbit 로그인 토큰 로그인, 계정별 기록 구분, 팀원 표시
탐색 기록 방문한 페이지의 주소·제목·도메인, 방문·종료 시각, 활동 시간, 이전 페이지 주소, 탭·창 번호, 검색어(검색 결과 페이지 주소에 포함된 경우) 탐색 흐름을 세션으로 정리, 기록 검색과 복원
페이지 본문 방문한 페이지에서 추출한 본문 텍스트(페이지당 최대 16,000자) 세션 요약, 검색, 질문 답변의 근거
AI 생성 정보 세션 제목·요약·키워드, 검색용 임베딩(수치 벡터), 질문과 답변 세션 정리, 검색, 질문 답변
화면 캡처(선택) 이용자가 켠 경우에만 보고 있는 탭의 화면 이미지. 기본은 이 기기에만 저장되며, “팀 화면 공유”를 켠 팀에 공유한 페이지의 캡처만 서버에 올립니다. 기록 미리보기, 팀원과 페이지 화면 공유
팀 정보 팀 이름·아이콘, 멤버와 역할, 공유한 세션, 팀 수집 시작·종료 기록, 팀 활동 기록(세션 제목·주소·본문은 저장하지 않음) 팀 워크스페이스 운영
설정·기기 정보 수집·동의 설정, 제외 사이트 목록, 기기 식별자(무작위 값) 이용자 설정 적용, 팀 수집을 기기별로 구분

서비스는 로그인하지 않았거나 수집을 끈 상태, 시크릿 창에서는 탐색 기록을 수집하지 않습니다. 민감 사이트 제외 설정이 켜져 있으면 금융·증권·카드·결제·일부 공공·건강보험 사이트와 로그인·결제 주소로 보이는 페이지를 기록하지 않습니다. AI 서비스로 보내는 주소에서는 쿼리 문자열과 식별자로 보이는 경로 조각을 제거합니다.

2. 보유 기간과 파기

  • 탐색 기록, 세션, 본문, 요약, 캡처는 이용자가 삭제하거나 계정 삭제를 요청할 때까지 보관합니다. 이용자는 서비스 안에서 세션과 방문 기록을 삭제할 수 있습니다.
  • 계정 삭제를 요청하면 지체 없이, 늦어도 30일 안에 계정과 관련 기록을 서버에서 삭제합니다.
  • 서버 백업은 장애 복구용으로 매일 만들어지며 최대 14일 보관 후 자동 삭제됩니다. 삭제한 정보도 이 기간 동안 백업에 남아 있을 수 있습니다.
  • 팀 활동 기록은 1년이 지나면 자동 삭제합니다. 팀이 공유 보관 기간을 정하면 기간이 지난 공유는 팀에서 자동으로 해제됩니다.
  • 확장 프로그램을 삭제하면 이 기기에 저장된 대기 기록과 캡처는 함께 지워지지만, 서버의 기록은 별도로 삭제를 요청해야 합니다.
  • 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

4. 팀 기능에서 다른 사람에게 보이는 정보

  • 팀에 공유한 세션은 팀원이 제목·요약·페이지 제목·주소(쿼리 제외)·방문 시각과 공유한 사람의 이름·사진을 볼 수 있습니다. 공유 후 그 세션에 추가되는 페이지도 보입니다.
  • 팀 수집을 켠 동안 이 기기에서 방문한 페이지는 세션으로 정리되어 팀에 자동 공유됩니다. 웹메일·메신저·검색 결과·로그인 화면으로 보이는 페이지와 이용자가 제외한 사이트는 팀으로 보내지 않습니다.
  • 공유를 해제하거나 팀을 나가면 팀원에게 더 이상 보이지 않으며, 원래 기록은 이용자에게 남습니다. 팀원이 이미 본 내용은 되돌릴 수 없습니다.
  • 팀원의 이메일은 팀 소유자·관리자와 본인에게만 보입니다.

5. 이용자의 권리

이용자는 언제든지 수집을 끄고, 기록을 조회·삭제하고, 팀 공유를 해제할 수 있습니다. 개인정보 열람·정정·삭제·처리정지나 계정 삭제를 원하면 아래 연락처로 요청해 주세요. 본인 확인 후 지체 없이 처리합니다.

6. 안전성 확보 조치

  • 이용자와 서버 사이의 통신은 HTTPS로 암호화합니다.
  • 데이터베이스와 검색 저장소는 외부에서 직접 접근할 수 없는 내부망에만 둡니다.
  • 모든 기록은 로그인한 계정 기준으로 접근을 제한하고, 팀 기록은 해당 팀원에게만 제공합니다.
  • 서버 접근 권한은 운영자로 한정하고, API 키 등 비밀값은 저장소와 로그에 남기지 않습니다.

7. 아동의 개인정보

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만 아동의 개인정보를 알고서 수집하지 않습니다.

8. Chrome 웹 스토어 사용자 데이터 정책 준수

Orbit이 Chrome 확장 프로그램과 Google API를 통해 받은 정보의 사용과 다른 앱으로의 전송은 Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용(Limited Use) 요건과 Google API 서비스 사용자 데이터 정책을 따릅니다. 수집한 정보는 위에서 설명한 탐색 기억 기능을 제공하고 개선하는 데에만 쓰며, 광고, 판매, 신용도 판단에 쓰지 않습니다. 사람이 정보를 직접 열람하는 경우는 이용자의 동의를 받은 경우, 보안·장애 대응, 법령 준수에 필요한 경우로 한정합니다.
